# Sales-blog engine

Tecxmate's own blog engine for sales / solution articles. No WordPress. Posts
are plain structured JSON, versioned in this repo, rendered by the same blog UI
as every other post, and filed under the **Guides** category.

## How it works

```
content/blog/sales/drafts/<slug>.json   ← one article each (structured content)
          │  node scripts/build-sales-posts.mjs   (validate + assemble)
          ▼
content/blog/sales/posts.json           ← the committed, deployed article set
          │  lib/seed-posts.ts  →  lib/sales-blog.ts (assembleSalesPost)
          ▼
lib/site-posts.ts  →  lib/wordpress.ts  →  /blog listing, /blog/<slug>, RSS, sitemap
```

- Articles are **drafts** until approved. Drafts are hidden on production and
  excluded from the sitemap and RSS. They are visible only on a deployment with
  `SHOW_BLOG_DRAFTS=true` (use a Vercel **preview** deploy to review them).
- A post written to the Vercel Blob store (via `POST /api/blog/publish`) with
  the same slug overrides its seed copy, so an article can be edited after the
  fact without a code change.

## Draft → review → publish

1. **Write / add** drafts under `drafts/` (see the article shape below, or copy
   an existing one). A batch can be generated by writer agents.
2. **Build:** `node scripts/build-sales-posts.mjs` — validates every draft
   against `salesPostSchema` and writes `posts.json`. Already-approved slugs
   keep their `published` status.
3. **Review:** deploy a preview with `SHOW_BLOG_DRAFTS=true` and read them at
   `/blog?category=Guides`.
4. **Approve:** `node scripts/approve-sales-post.mjs <slug> [...]` (or `--all`),
   commit, and deploy. `--unpublish <slug>` reverts one to draft; `--list` shows
   current statuses.

## Article shape (`drafts/<slug>.json`)

Validated by `salesPostSchema` in `lib/sales-blog.ts`. Character counts inclusive.

| field | required | rule |
|---|---|---|
| `slug` | yes | lowercase kebab-case, 3–100, unique; also the filename |
| `language` | no | `en` \| `zh` \| `vi` (default `en`) |
| `title` | yes | 8–120 chars |
| `excerpt` | yes | 40–220 chars, no CTA |
| `coverImage` | no | a path under `/public` (e.g. `/graphics/Strategy & Research.png`) |
| `keyTakeaways` | yes | 3–6 items, each 10–180 |
| `sections` | yes | 3–6 × `{ heading (4–90), paragraphs: 1–4 × 40–900 }` |
| `tags` | yes | 3–8 items, each 2–32 |
| `faq` | no | 0–4 × `{ q (5–180), a (10–700) }` |

**Do not** put URLs, phone numbers, emails, prices, invented clients, metrics, or
case studies in the body — see `/ASSISTANT.md`. The standard call-to-action
(book a call / quote) is appended automatically by `assembleSalesPost`.
